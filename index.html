What the solver is doing
01

Start with the rules

The grid is the state space. Each empty cell stores a domain containing the values that do not violate its row, column, or box constraints.

02

Pick the tightest spot

The Minimum Remaining Values heuristic selects the cell with the fewest legal options, reducing unnecessary search.

03

Show the thinking

Each iteration is recorded as a decision, deduction, contradiction, or backtrack so the algorithm can be inspected like an experiment.
